PyCrystallography
=================

PyCrystallography is a modern orchestration layer for composite diffraction analysis. The library
delegates crystallographic maths to `orix <https://orix.readthedocs.io>`_ and structure handling to
`pymatgen <https://pymatgen.org>`_, focusing on configuration management, plug-in extensibility and
user experience.

Highlights
----------

* Strict configuration schema powered by Pydantic with support for environment and CLI overrides.
* Adapters that bridge pycrystallography's domain models to orix (orientations, variants) and
  pymatgen (structure loading, TEM diffraction calculators).
* Plug-in architecture for diffraction calculators discoverable through entry points. A composite
  TEM/SAED implementation is included by default.
* Typer-based CLI (``pcg``) with dry-run mode, logging controls and multi-format outputs.

Quick start
-----------

1. Install the project in a virtual environment::

       pip install -e .[dev]

2. Validate the curated Burgers OR configuration (YAML) and print the
   normalised representation::

       pcg config validate --config examples/quickstart.yaml --print

3. Generate a composite Burgers OR pattern for Zr (dry run). This command
   reads ``examples/or_zr.yaml`` for the orientation metadata, enumerates all
   symmetry-equivalent variants with ``orix`` and assembles a composite TEM
   pattern::

       pcg composite tem --relation burgers-zr --config examples/quickstart.yaml --dry-run

4. Compute a powder XRD pattern for the α-Zr phase using the built-in
   registry::

       pcg powder xrd --phase alpha-zr --config examples/quickstart.yaml --dry-run

   Drop the ``--dry-run`` flag to write a ``CSV`` of the peak list and a
   ``PNG`` plot under ``./output``. Switch ``--phase`` to ``beta-zr`` to
   produce the body-centred cubic pattern.

Outputs (CSV + PNG + HTML) are written to ``./output`` by default. Use
``--out`` to change the destination. The composite workflow saves an
interactive-ready PNG generated by :class:`~pycrystallography.plotting.CrystallographicFigure`
alongside an offline HTML report containing the variant catalogue, CIF metadata
validation warnings, Euler angles and plotting configuration snapshot.

See ``docs/`` for tutorials on extending the calculator registry, authoring
orientation YAML documents and building plug-ins. The ``examples/`` directory
contains the reference Burgers OR YAML, a pre-wired configuration, and Jupyter
notebooks demonstrating the interactive plotting and variant toggling APIs.
