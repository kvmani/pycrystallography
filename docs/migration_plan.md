# Migration plan: restoring interactive diffraction tooling on `advanced`

## Current architecture (before)

```
pycrystallography/
├── adapters/
│   ├── orix_adapter.py        # Orientation math wrappers
│   └── pymatgen_adapter.py    # Structure/diffraction facades
├── analysis/
│   ├── calculators/           # Composite TEM calculator only
│   └── orientation_mapping.py # Mapping utilities (textual)
├── plotting/
│   ├── composite.py           # Static scatter plot helper
```

infrastructure, HTML reports, CLI affordances and end-to-end documentation.

### Public API surface

| Module | New exports |
| ------ | ----------- |
| `pycrystallography.io` | `load_cif_structure`, `OrientationYAMLDocument`, `load_orientation_library` |
| `pycrystallography.core` | `VariantManager`, `MarkerPalette`, `OrientationLibrary` |
| `pycrystallography.plotting` | `CrystallographicFigure`, `AnnotationManager` |
| `pycrystallography.analysis.reports` | `HtmlReportBuilder` |
| `pycrystallography.cli` | `pcg plot composite`, `pcg report phase` |

### Data & dependency flow

1. **CIF ingestion** (`io.cif.load_cif_structure`)
   - Reads CIF via `pymatgen.Structure.from_file`
   - Normalises lattice/space-group metadata
   - Emits `StructureSummary` (structure + symmetry report + warnings)
2. **OR YAML loading** (`io.or_yaml.load_orientation_library`)
   - Validates against `schemas/or_schema.yaml`
   - Resolves CIF path relative to YAML
   - Converts hkl/uvw definitions into Cartesian vectors using CIF structure
   - Generates canonical `OrientationRelation` objects with orientation matrices from `orix`
3. **Variant generation**
   - `VariantGenerator` (existing adapter) enumerates variants using parent/child symmetry
   - `VariantManager` stores `VariantState` objects with deterministic IDs and default visibility from YAML `plot` section
4. **Plotting pipeline**
   - `CrystallographicFigure` consumes `CompositePattern`, `VariantManager`, `PlotSettings`
   - Each variant’s reflections mapped to scatter artists with unique marker/colour from `MarkerPalette`
   - Hover + click events feed into `AnnotationManager` (layout) and `TooltipManager`
5. **Reporting**
   - `HtmlReportBuilder` receives `Phase` metadata, OR definitions, variant list, and figure handles
   - Embeds static images + JSON configuration snapshot for reproducibility

### CIF ingestion model

- Trust CIF as source of truth; optional `space_group`/`lattice_parameters` fields are validated against parsed structure.
- Provide `StructureSummary.validate(metadata)` returning mismatches/warnings.
- Cache loaded structures keyed by file hash to avoid repeated I/O during CLI sessions.

### Orientation-relation YAML schema highlights

- Schema stored at `schemas/or_schema.yaml`; enforced via `jsonschema` (generated by Pydantic).
- Supports multiple OR entries per phase, optional variant defaults (`visibility`, `marker`, `color`).
- Euler angles stored in degrees, Bunge (ZXZ) convention, validated via `orix` conversion.

### Plotting pipeline

- Matplotlib backend; interactive widgets from `matplotlib.widgets`.
- Tooltip implementation reuses a single `Annotation` artist, updated on motion events.
- Annotation layout uses greedy polar sweep with collision detection using renderer bounding boxes.
- Export helpers produce PNG/SVG with DPI configured in `plot_settings.yaml`.

### Performance budget & measurement plan

| Stage | Budget | Measurement |
| ----- | ------ | ----------- |
| Variant enumeration | < 25 ms for 24 variants | `tests/perf/test_variants.py` Hypothesis benchmark |
| Spot projection & scatter update | < 150 ms for 2k reflections | `tests/perf/test_plotting.py` using synthetic data |
| Toggle update latency | < 300 ms | Matplotlib draw time measured via `FigureCanvasAgg` |
| Report generation | < 1 s including image save | `tests/perf/test_report.py` |

Caching strategies:
- Reuse TEM calculator inputs across variant toggles via memoised `CompositePattern` slices.
- Annotation layout caches bounding boxes per variant/d label set until scatter data changes.

### Migration milestones

1. **Schema & loaders**: land CIF + OR YAML validators, update config and tests.
2. **Variant manager + plotting core**: implement `CrystallographicFigure` with toggles, tooltips, annotations, unique markers.
3. **Report builder**: create HTML pipeline and CLI entry point.
4. **Docs & examples**: refresh README, user/dev guides, notebooks.
5. **Performance harness**: add benchmarks and enforce thresholds in CI.

### Risks & mitigations

- *Dependency drift*: pin `orix` / `pymatgen` versions in `pyproject.toml` and document tested versions.
- *Matplotlib backend quirks*: use `Agg` for tests; expose backend override env var in CLI.
- *Large CIF assets*: reuse curated CIFs from `data/structureData` to avoid repository bloat.
- *Tooltip/annotation flicker*: throttle motion events and use cached nearest-point lookup (KD-tree) with tolerance window.

### Success criteria

- Benchmarks meet the stated thresholds.
- HTML report renders offline with embedded assets.
- Users can execute `pcg plot composite --or examples/or_zr.yaml` end-to-end.
